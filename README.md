# CafeFlow Clone

An independently implemented cafe and restaurant operations SaaS inspired by publicly observable CafeFlow workflows. This project is not affiliated with CafeFlow.

## Stack

- Next.js 14 + React + TypeScript
- Tailwind CSS
- Planned: PostgreSQL + Prisma, secure authentication, realtime order events, payment provider integration

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Initial scope

- Operations dashboard shell
- Orders, POS, kitchen display, menu, inventory, customers, analytics and settings navigation
- Responsive layout foundation

## Roadmap

1. Recreate and validate the public-facing workflows and UI patterns.
2. Implement persistent data models and role-based access.
3. Add POS, QR ordering, kitchen workflows, inventory and reporting.
4. Integrate payments and realtime updates using provider-approved APIs.
5. Add automated tests and deployment documentation.
